# LAST LINE: EARTHFALL (Prototype)

A cinematic single-page prototype for the game concept **LAST LINE: EARTHFALL**.

## Run locally

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

## What's included

- Hero section with app identity and hook.
- Core gameplay loop and enemy roster.
- Interactive wave simulator with escalating threat tiers.
- Mid-wave upgrade card choices.
- Visual Adaptive evolution phases based on wave progression.

## Tech

- Vanilla HTML/CSS/JS (no dependencies).
